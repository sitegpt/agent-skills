# SiteGPT agent-skills repo

Skills for building and operating SiteGPT chatbots from AI agents.

- Skills live in skills/ (standard SKILL.md format; installable via
  skills.sh and ClawHub).
- The Claude Code plugin manifest is .claude-plugin/plugin.json; the
  Agent Plugins manifest is plugin.json at the repo root.
- Prefer the SiteGPT CLI (`npm install -g @sitegpt/cli`) or the remote
  MCP server (https://sitegpt.ai/mcp) for live operations.
- Anonymous agent onboarding: https://sitegpt.ai/auth.md
